# 概要

PS Banshee は、**Recorded Future プロフェッショナルサービス サイバーセキュリティエンジニアリングチーム**によって開発・保守されているコマンドラインインターフェース（CLI）ツールです。このプロジェクトは、セキュリティ専門家が包括的なターミナルベースのコマンドセットを通じて、Recorded Future インテリジェンスに迅速かつ効率的にアクセスできるよう設計されています。

## プロジェクトサポート

PS Banshee は Recorded Future のプロフェッショナルサービスチームによって公式にサポートされています。私たちのサイバーセキュリティエンジニアは、セキュリティオペレーションや調査を効率化するためにこのツールを構築しました。
