# IOC エンリッチメント

## ユースケースの概要
Indicators of Compromise (IOC) を Recorded Future のリスクスコア、関連エンティティ、アナリストコンテキストでエンリッチし、セキュリティオペレーションセンター (SOC) のトリアージと脅威調査を加速します。

IOC エンリッチメントの詳細については、[こちら](https://support.recordedfuture.com/hc/en-us/articles/115000897208-Risk-Scoring-in-Recorded-Future)をクリックしてください。

## 課題
アナリストは IP アドレス / ドメイン / URL / ハッシュ / 脆弱性の調査にツール間のピボット作業に時間を費やしており、調査の遅延やレスポンスタイムの増大を招いています。複数のソースにわたる脅威インテリジェンスの手動での相関付けは、分析のギャップを生み出し、インシデントレスポンスを遅延させます。

## ソリューション
[`banshee ioc`](../../reference/commands.md#banshee-ioc) コマンドを使用して、PS Banshee で直接 IOC をエンリッチします。個々のインジケーターを検索し、リスクスコア、AI インサイト、脅威アクター / マルウェアの関連付けを取得します。さまざまなフィルタリングオプションを使用して IOC を検索し、高リスクのインジケーターを特定します。エンリッチされたコンテキストを活用して、組織が直面している脅威を把握し、インシデントレスポンスの意思決定を加速します。
