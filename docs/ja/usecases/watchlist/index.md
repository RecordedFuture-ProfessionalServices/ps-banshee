# ウォッチリスト管理

## ユースケースの概要
Recorded Future のウォッチリストを使用して、厳選された優先度の高いエンティティ（企業、ドメイン、IP、脆弱性、役員、サプライヤー）を管理し、セキュリティオペレーションセンター（SOC）にとって最も重要な事項にアラートとインテリジェンスを集中させます。

ウォッチリストの詳細については、[こちら](https://support.recordedfuture.com/hc/en-us/articles/115005092427-Watch-Lists)をクリックしてください。

## 課題
脅威環境とビジネスの優先事項は常に変化しています。ウォッチリストを積極的に管理しないと、アラートやインテリジェンスの範囲が広くなりすぎ、アナリストが最も重要な事項に迅速に集中することが難しくなります。

## 解決策
[`banshee list`](../../reference/commands.md#banshee-list) コマンドを使用して、PS Banshee で直接ウォッチリストを作成・管理します。CSVをアップロードして一括変更を行ったり、エンティティを個別に追加したり、新しいエンティティのキュレーションをリクエストしたりすることができます。ウォッチリストをインテリジェンスゴールにマッピングして、関連するアラートのみがトリガーされるようにします。リストを統合または再編成する際は、[`banshee list copy`](../../reference/commands.md#banshee-list-copy) を使用して、あるリストから別のリストにエンティティをマージします（オプションで `--overwrite` を指定）。ブランド、ドメイン、役員、サプライヤー、脆弱性、ロケーションなどのリストを定期的に見直し、更新して、カバレッジが進化するリスク状況を反映していることを確認してください。
