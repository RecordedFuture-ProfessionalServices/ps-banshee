# การขอความช่วยเหลือ

## เมนูความช่วยเหลือ

สามารถใช้แฟล็ก `--help`, `-h` เพื่อดูเมนูความช่วยเหลือสำหรับคำสั่ง เช่น สำหรับ [banshee](../reference/commands.md#banshee):

```bash
banshee --help
```

เพื่อดูเมนูความช่วยเหลือสำหรับคำสั่งเฉพาะ เช่น สำหรับ [banshee pcap](../reference/commands.md#banshee-pcap):

```bash
banshee pcap --help
```

## การดูเวอร์ชัน

เมื่อต้องการขอความช่วยเหลือ สิ่งสำคัญคือต้องระบุเวอร์ชันของแพ็กเกจ ps-banshee ที่ใช้งานอยู่ เนื่องจากบางครั้งปัญหาดังกล่าวได้รับการแก้ไขแล้วในเวอร์ชันที่ใหม่กว่า

เพื่อตรวจสอบเวอร์ชันที่ติดตั้งอยู่:

```bash
banshee --version
```

## การแก้ไขปัญหา

หากคำสั่งล้มเหลวในลักษณะที่ไม่คาดคิด สามารถใช้แฟล็ก `--debug` เพื่อรับข้อมูลข้อผิดพลาดที่ละเอียดยิ่งขึ้น:

```bash
banshee --debug ioc search ip -p
```

ผลลัพธ์จะแสดงตำแหน่งที่แน่ชัดที่คำสั่งล้มเหลว จากนั้นสามารถส่งข้อมูลนี้ไปยังทีมสนับสนุนเพื่อช่วยแก้ไขปัญหาได้
