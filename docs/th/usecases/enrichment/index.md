# IOC Enrichment

## Use Case Summary
เสริมข้อมูล Indicators of Compromise (IOCs) ด้วยคะแนนความเสี่ยง, เอนทิตีที่เกี่ยวข้อง, และบริบทจากนักวิเคราะห์ของ Recorded Future เพื่อเร่งกระบวนการ triage และการสืบสวนภัยคุกคามของ Security Operations Center (SOC)

สำหรับข้อมูลเพิ่มเติมเกี่ยวกับ IOC enrichment คลิก[ที่นี่](https://support.recordedfuture.com/hc/en-us/articles/115000897208-Risk-Scoring-in-Recorded-Future)

## Issue
นักวิเคราะห์ต้องเสียเวลาสลับใช้งานระหว่างเครื่องมือต่าง ๆ สำหรับ IP, โดเมน, URL, แฮช, และช่องโหว่ ซึ่งทำให้การสืบสวนล่าช้าและเพิ่มเวลาในการตอบสนอง การเชื่อมโยงข้อมูล threat intelligence จากหลายแหล่งด้วยตนเองก่อให้เกิดช่องว่างในการวิเคราะห์และทำให้การตอบสนองต่อเหตุการณ์ล่าช้า

## Solution
เสริมข้อมูล IOCs โดยตรงใน PS Banshee โดยใช้คำสั่ง [`banshee ioc`](../../reference/commands.md#banshee-ioc) ค้นหา indicator แต่ละรายการเพื่อรับคะแนนความเสี่ยง, ข้อมูลเชิงลึกจาก AI, และความเชื่อมโยงกับ threat actor และ malware ค้นหา IOCs โดยใช้ตัวเลือกการกรองต่าง ๆ เพื่อระบุ indicator ที่มีความเสี่ยงสูง ใช้ประโยชน์จากบริบทที่ได้รับการเสริมข้อมูลเพื่อทำความเข้าใจภัยคุกคามที่องค์กรกำลังเผชิญอยู่ และเร่งกระบวนการตัดสินใจในการตอบสนองต่อเหตุการณ์
